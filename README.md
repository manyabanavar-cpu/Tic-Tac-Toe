# ❌ Tic-Tac-Toe
A clean, interactive, browser-based execution of the classic Tic-Tac-Toe game. I built this project to deeply master foundational programming architecture and user interface interactivity.
## 🚀 Features
- **Dynamic DOM Manipulation:** Real-time rendering of player turns (X and O) without refreshing the page.
- **State Management & Logic:** Built-in win-condition algorithms that instantly scan the grid for horizontal, vertical, and diagonal matches.
- **Instant UI Reset:** A smooth game reset mechanism allowing users to restart their match with a single tap.
## 🛠️ Tech Stack
- **Languages:** JavaScript, HTML5, CSS3
